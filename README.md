# アルバイト給料見込み計算

シフト表を貼り付けて、給料見込み・合計勤務時間・勤務日数・日別内訳を表示する静的Webアプリです。Streamlit版をHTML・CSS・JavaScriptに置き換えました。

**ビルド・パッケージのインストール・サーバー処理は不要です。** 外部ライブラリやCDNを使わず、入力内容はブラウザ内だけで処理します。保存や送信は行いません。スマートフォンでも利用できます。

## 起動

`index.html` をブラウザで開くだけで使えます。ローカルサーバーで確認する場合は、任意で次を実行します。

```sh
python3 -m http.server 8000
```

`http://localhost:8000` を開きます。Pythonはアプリの動作には必要ありません。

## GitHub Pagesで公開

1. このリポジトリの変更をGitHubの公開用ブランチにpushします。
2. GitHubの **Settings → Pages** を開きます。
3. **Source → Deploy from a branch** を選択します。
4. 公開用ブランチ（例：`main`）と **/(root)** を選び、Saveします。
5. 公開処理の完了後、Pagesに表示されるURLを開きます。

パスは相対指定のため、`https://ユーザー名.github.io/リポジトリ名/` でも動作します。`.nojekyll` を同梱しています。設定の詳細は[GitHub公式ドキュメント](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)を参照してください。

## 入力方法

勤務年を選び、シフト表を貼り付けて「給料を計算する」を押します。

```text
日付    勤務時間    労働時間    休憩時間
10/05(月)    12:00～18:00    06:00    00:00
10/10(土)    17:00～20:00    03:00    00:00
10/12(月)    13:00～17:30    04:30    00:00
```

- タブ・スペース区切り、全角数字、`～`・`〜`・`~`・`-` に対応します。
- 曜日は省略可能です。祝日・曜日の判定には実際の日付を使います。
- 労働時間・休憩時間の2列はまとめて省略できます。
- 勤務時間欄が `－`・`ー`・`休み`・`公休`・`休日` の行は読み飛ばします。
- 年のない日付はすべて画面の勤務年を使います。年をまたぐ場合は `2027/01/03(日)` のように明記してください。
- 不正な日付・時刻、勤務時間の重複、労働時間の不一致は行番号付きで表示し、全行を修正するまで合計を表示しません。
- 休憩がある場合は、その時間を除く勤務区間を別々の行に入力します（例：`10/05 10:00～12:00` と `10/05 13:00～17:00`）。休憩時間だけでは、どの時給帯から差し引くべきか分からないためです。同じ日の複数区間は勤務日数では1日と数えます。
- 日をまたぐ勤務は、`10/05 22:00～24:00` と `10/06 00:00～02:00` のように分けます。

## 計算ルール

2026年10月1日以降の勤務には以下の時給を適用します。基本時給を55円引き上げ、午後＋50円、夕方・土日祝＋150円の加算を維持しています。9月以前の勤務には旧時給（1,140円・1,190円・1,290円）を適用し、改定前後を含む入力も日付ごとに計算します。

| 条件 | 時給 |
| --- | ---: |
| 平日 13:00より前 | 1,195円 |
| 平日 13:00〜17:00 | 1,245円 |
| 平日 17:00以降 | 1,345円 |
| 土日祝日 | 1,345円 |

時間帯をまたぐ勤務は分単位で分割します。計算途中は「勤務分数 × 時給」の整数で保持し、表示時に60で割って円未満を四捨五入します。日別表示と合計表示には丸めによる差が生じる場合があります。深夜・時間外手当、税金、交通費は含みません。複数月の入力はまとめて合計します。

旧版は休憩列を無視していましたが、この版では休憩ありの行を検出して修正を案内します。旧版の現在月に基づく年の推測も、明示的な年の指定に変更しました。

## 祝日データ

[内閣府「国民の祝日について」](https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html) のCSVを加工して `holidays.js` に同梱しています。2026年10月3日取得。**1955〜2027年**に対応し、振替休日・国民の休日も含みます。未収録の年は、誤って平日扱いにせずエラーにします。

翌年以降のデータが公開されたら、次のコマンドで更新し、生成された `holidays.js` をpushしてください（更新時のみPythonと通信が必要です）。

```sh
python3 scripts/update_holidays.py
```

ダウンロード済みCSVを使う場合：`python3 scripts/update_holidays.py /path/to/syukujitsu.csv`。

## ファイル構成

- `index.html`：画面
- `styles.css`：レスポンシブ表示
- `calculator.js`：入力解析と給与計算
- `app.js`：画面操作と結果表示
- `holidays.js`：祝日データ
- `scripts/update_holidays.py`：祝日更新用（公開時は不要）
- `tests/calculator.test.cjs`：計算テスト（公開時は不要）

テストはNode.jsの標準機能だけで実行できます。npm installは不要です。

```sh
node --test tests/calculator.test.cjs
```
